### Selected work

- **[EgoBlind-RA](https://github.com/juliavekim/EgoBlind-RA)** — risk-adaptive visual assistance for blind and low-vision users. With Xander Backus, I compared urgency-conditioned response policies. My work on a unified Kimi-VL LoRA adapter reduced composite loss by **38%** against the uniform-policy baseline on **1,283 test examples**; three DPO variants regressed relative to supervised fine-tuning. The CLIP urgency classifier achieved **0.905 ROC-AUC**.
- **Personalized Instruction** — a Python pipeline for MIT’s *AI for Leaders* course, connecting learning objectives, misconception-focused questions, and personalised remediation videos. Reusable content, staged execution, logging, text-to-speech, and FFmpeg assembly. [Project overview](https://juliavekim.github.io/#work).
- **[StarCLIP](https://juliavekim.github.io/publication/contrastive-learning-stellar-spectra/)** — Cambridge thesis on contrastive learning for stellar spectra, aligning observations across modalities in a shared latent space.
